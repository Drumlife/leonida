# Leonida Tracker

Outil personnel non officiel pour GTA VI : carte de Leonida, points à collectionner,
progression et itinéraire par la route entre les points.

- App : `app/` (HTML + JavaScript, aucune compilation). Ouvrir `app/index.html` via un serveur web.
- Synchronisation entre appareils (facultative) : Supabase, voir `supabase/leonida_sync.sql` et `app/config.js`.
- Réseau routier : extrait des tuiles par les scripts de `tools/`.
